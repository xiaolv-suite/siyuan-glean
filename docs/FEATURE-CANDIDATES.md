## 候选功能列表

### FC-001：原生编辑器文本/块拖拽至侧栏或工作台 DropZone 自动收录与制卡
- **是什么**：在侧边栏 Dock 和工作台面板增加 HTML5 原生拖拽放置区（DropZone）。用户在思源编辑器中鼠标拖拽选中的文本或块手柄直接拖进小驴拾遗窗口即可自动触发收录或弹出闪卡制作浮层。
- **解决什么问题**：目前从编辑器到读库主要依靠右键菜单或快捷键，缺少直觉化的“拖拽即收纳”物理交互质感。
- **影响哪类用户**：习惯使用双屏或左右分屏对照排版、重度依赖鼠标拖拽收集资料的研究型用户。
- **预估成本**：中等（约 0.5 天）。需在 `DockPanel.svelte` 容器挂载全局 `dragenter` / `dragover` / `drop` 监听，解析拖拽数据中的纯文本或思源 block-id，并设计微弱虚线放置提示框。
- **与现有功能是否重叠**：与编辑器右键菜单「小驴拾遗：加入读库」以及快捷键 `addToList` 解决相同目标，但提供了更便捷的直觉化输入路径。
- **状态**：✅ 已完成闭环交付（对应待办编号 `BL-25`）

### FC-002：命令面板新增「漫游盲盒（随机抽选）」全局指令
- **是什么**：在 `src/index.ts` 中注册 `cmd.roamingPick`（小驴拾遗：漫游盲盒），支持用户在思源任意位置按 `Ctrl+P` 命令面板直接调起漫游盲盒抽屉。
- **解决什么问题**：目前漫游盲盒主要在今日拾遗卡和工作台内部唤起（或通过快捷键 `B`），在全屏正文阅读或写作中如果突然想“随便看一篇”，必须先切换到工作台才能开盲盒。
- **影响哪类用户**：喜欢碎片时间“无负担偶遇式阅读”、高频使用命令面板的键盘流用户。
- **预估成本**：极小（约 0.1 天）。仅需在 `src/index.ts` 的 `onload` 中增加一条 `this.addCommand({ langKey: "cmd.roamingPick", callback: () => openRoamingDialog(this) })` 及双语 i18n 映射。
- **与现有功能是否重叠**：现有功能已有漫游盲盒抽屉组件（`RoamingDrawerDialog`），仅为增加全局命令面板唤起入口，无重复实现。
- **状态**：✅ 已完成闭环交付（对应待办编号 `BL-26`，待排期推进）

### FC-003：思源顶栏小麦穗图标右键扩展快捷菜单
- **是什么**：右键点击思源笔记顶部导航栏的小麦穗图标时，弹出紧凑上下文菜单（例如：直接打开今日拾遗、直接打开划线摘录墙、直接打开阅读统计、快速抽一篇漫游好文、打开设置）。
- **解决什么问题**：目前左键点击顶栏图标固定打开读库工作台主页签；对于只想快速看一眼热力图统计或摘录墙的用户，需要多点一次左侧导轨切换。
- **影响哪类用户**：频繁在多个模块间跳转的桌面端日常用户。
- **预估成本**：小（约 0.2 天）。利用思源顶栏元素的 `contextmenu` 原生事件，调用思源提供的上下文菜单组件弹出快捷子菜单。
- **与现有功能是否重叠**：与工作台内部的导轨切换存在入口并列，但缩短了从全局任意页面直达子视图的操作链路。
- **状态**：✅ 已完成闭环交付（对应待办编号 `BL-27`，待排期推进）

- **是什么**：在设置维护页提供“导出设置草稿 JSON”和“从 JSON 恢复设置”，方便多端或换库快速同步个人偏好。
- **解决什么问题**：当用户在家庭电脑和办公电脑两台设备上使用思源时，免去重复配置 8 大类设置项的成本。
- **影响哪类用户**：拥有多台设备（PC/Mac/笔记本）跨场景办公的用户。
- **预估成本**：极小（约 0.1 天）。现有已有 `settings.json` 结构，提供下载与上传即可。
- **与现有功能是否重叠**：现有 `BackupPanel` 是备份文章元数据，此项是单纯的插件配置导出。
- **状态**：✅ 已完成闭环交付（对应待办编号 `BL-44`，待排期推进）
